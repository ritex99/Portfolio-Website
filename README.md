# Personal Portfolio — React + Tailwind CSS + PostCSS

## Stack
- **React 18** (via Vite)
- **Tailwind CSS v3** (utility-first styling)
- **PostCSS** (autoprefixer)
- **Google Fonts** — Syne (display), JetBrains Mono, DM Sans

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Build for production
npm run build
